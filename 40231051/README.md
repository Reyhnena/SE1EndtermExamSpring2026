## Project
Secure Messenger with End-to-End Encryption

## Architecture
The system is designed using Microservices Architecture.

Main services:
- API Gateway
- Auth Service
- User Service
- Message Service
- Key Directory Service
- Media Service
- Group Service
- Notification Service

## Design Patterns
- Factory Method: creates different message types.
- Observer: notifies devices and notification service when a new message is sent.
- Decorator: adds encryption behavior to messages.

Function bodies are not implemented because only the code structure is required.
